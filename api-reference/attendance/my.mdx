  data. It is not an official EmPay deployment.
</Note>

## Demo authentication

The playground is prefilled with the employee demonstration bearer token, so the
request is ready to send. To retrieve the same token yourself, sign in to
`POST /api/auth/login` with `employee@empay.example` and `EmpayDemo123!`.
