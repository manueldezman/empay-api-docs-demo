The EmPay API follows OpenAPI 3.0.3. Use the specification to:

- Generate client libraries.
- Import the API into testing tools.
- Integrate the API with AI agents and other developer tools.
- Build automated documentation and contract tests.

## For AI agents

AI agents can discover and consume the API documentation through these public
resources:

| Resource               | URL                                                                                                    | Purpose                                     |
| ---------------------- | ------------------------------------------------------------------------------------------------------ | ------------------------------------------- |
| OpenAPI specification  | [`https://empay-sample.mintlify.site/openapi.yaml`](https://empay-sample.mintlify.site/openapi.yaml)   | Complete structured API contract            |
| `llms.txt`             | [`https://empay-sample.mintlify.site/llms.txt`](https://empay-sample.mintlify.site/llms.txt)           | Concise documentation discovery index       |
| Full LLM documentation | [`https://empay-sample.mintlify.site/llms-full.txt`](https://empay-sample.mintlify.site/llms-full.txt) | Complete documentation in one text resource |

Individual pages are also available as Markdown by appending `.md` to any page
URL.
