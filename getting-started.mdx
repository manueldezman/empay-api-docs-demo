Send an authenticated attendance request and inspect the response. The complete
workflow takes about five minutes.

## Before you start

Install `curl` if it is not available on your computer.

Run the following command to check whether `curl` is installed:

```bash
curl --version
```

If the command is not recognized, [install `curl` from the official curl
website](https://curl.se/) for your operating system before continuing.

<Info>
  **NOTE**

The account credentials and access token are prefilled in the requests so you
can begin immediately.

</Info>

## Base URL

```text
https://empay-api-docs-demo.vercel.app
```

## Verify the response

Success returns HTTP `200`, `success: true`, and an array of attendance
records:

```json
{
  "success": true,
  "data": [
    {
      "id": 1,
      "employee_id": 4,
      "full_name": "Ada Okafor",
      "department": "Engineering",
      "date": "2026-08-03",
      "check_in": "08:52:00",
      "check_out": "17:08:00",
      "status": "present",
      "work_hours": 8.27
    },
    {
      "id": 2,
      "employee_id": 4,
      "full_name": "Ada Okafor",
      "department": "Engineering",
      "date": "2026-08-04",
      "check_in": "09:03:00",
      "check_out": "17:15:00",
      "status": "present",
      "work_hours": 8.2
    }
  ]
}
```

If the response returns `401`, confirm that the header begins with `Bearer` and
that the token has no missing characters.
